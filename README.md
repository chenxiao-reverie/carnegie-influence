## 使用方式

本技能支持四种调用方式：

```
# 1. 不带参数 — 加载核心框架作为参考
"如何用卡耐基的方式说服别人？"

# 2. 带主题 — 查找已索引的主题
"什么是「是，是」法？"
"自重感饥渴是什么意思？"

# 3. 带章节 — 加载具体章节
"ch05 讲了什么？"
"给我讲林肯克制法的那一章"

# 4. 浏览 — 查看完整索引
"你有哪些章节？"
```

当你询问的主题未在核心框架中覆盖时，技能会自动读取相关章节文件再回答。

## 核心框架

### 第一原理：自重感饥渴

**人类天性至深的本质，就是渴求为人所重视。** ——威廉·贾姆士

所有技巧都建立在这个洞察上：满足对方这种感觉，你就能影响任何人。

### 三大核心原则

| # | 原则 | 一句话 |
|---|------|--------|
| 1 | **不批评、不责怪、不抱怨** | 批评如鸽，终将飞回；批评激起防御，从不带来改变 |
| 2 | **诚于嘉许，宽于称道** | 真诚的赞美是满足对方自重感的最直接方式 |
| 3 | **引起他人渴望** | 唯一让别人做某事的方法：让他自己想做 |

### 使人喜欢的六种方法

真诚对别人感兴趣 · 微笑 · 记住姓名 · 倾听 · 谈论对方兴趣 · 使对方感到重要

### 说服十二法（精要）

- **「是，是」法**：先谈共同点，让对方连连说"是"，再引导结论
- **富兰克林式谦让**：避免争辩，一滴蜂蜜比一加仑胆汁捕到更多苍蝇
- **挑战规则**：提出胜过别人的挑战，激发争胜欲望
- **求助法**：让对方觉得主意是他的，他就会全力执行
- **苏格拉底辩论法**：连续提问让对方说"是"，最终自己得出结论

### 领导力九法（精要）

- **保持面子**：批评时给对方台阶
- **使错误看起来容易改正**：用鼓励让对方相信"这很简单"
- **给好名字**：公开赋予积极标签，对方会努力配得上
- **民主商谈**：用提问代替命令

## 范围与限制

- ✅ 技能仅覆盖《人性的弱点》一书内容，不越界回答其他主题
- ✅ 所有技巧都经过真实历史案例验证（林肯、罗斯福、洛克菲勒等）
- ⚠️ 书中部分案例源自 20 世纪初美国社会背景，使用时需结合当代文化语境判断
- ⚠️ **真诚是根基**——没有真诚的"技巧"只是操纵。卡耐基本人反复强调：这些方法必须出自真心
